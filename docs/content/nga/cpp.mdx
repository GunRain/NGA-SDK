C++ 部分主要提供一些辅助函数

主要分为如下功能:

- 标准库通用: `nga-std.hh`
- POSIX 通用: `nga-posix.hh`
- Android 按键事件监听: `nga-key.hh`

## 引入依赖

在项目中添加文件后，直接 `#include` 即可:

```cpp
#include "nga-std.hh" // 标准库通用
#include "nga-posix.hh" // POSIX 通用
#include "nga-key.hh" // Android 按键事件监听
```

## 使用方法

文件中已写注释，直接参考注释即可
